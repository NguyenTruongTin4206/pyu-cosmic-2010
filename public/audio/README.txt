THÊM NHẠC NỀN MẶC ĐỊNH
1. Đổi tên file nhạc (MP3/OGG/WAV) thành: nhac-nen.mp3
2. Chép vào thư mục này: public/audio/nhac-nen.mp3
3. Chạy lại "npm run dev" (hoặc "npm run build").
Nếu file không tồn tại, trang vẫn chạy bình thường; người xem bấm "Chọn nhạc" để chọn file từ máy.
Chỉ dùng nhạc bạn có quyền sử dụng.
